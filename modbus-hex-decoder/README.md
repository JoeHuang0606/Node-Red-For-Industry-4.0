# 🔍 Modbus Hex 解碼器 (`modbus-hex-decoder`)

> **分類**：`Joe-Tools`  
> **難易度**：⭐小白友善

---

## 💡 一秒看懂
這個節點是把從 PLC / Modbus 讀回來的**一串數字**，直接還原成大寫的 **16 進位 (HEX) 字串**。  
例如讀到 `[18, 52, 86]` 轉成 `"123456"`，方便你查看原始 Hex 碼。

---

## 🎯 什麼時候用它？
* 從 Modbus 讀取 RFID 標籤、設備 ID、Mac 地址時。
* 需要把整列 Registers 快速串成連續 HEX 碼。

---

## 📥 輸入資料 (Input)
輸入 Modbus Read 節點出來的陣列：
```json
{
  "payload": [18, 52, 86, 120]
}
```

---

## ⚙️ 面板屬性設定指南

| 設定項目 | 小白白話說明 | 建議預設值 |
| :--- | :--- | :--- |
| **節點名稱** | 自訂顯示名稱 | `Modbus Hex 解碼器` |
| **擷取長度** | 只取前面幾個數字進行轉換 | `12` |
| **Hex 位數補齊** | 每個數字轉成 Hex 要補滿幾位數 | Byte 填 `2` (例如 0A) / Register 填 `4` (例如 000A) |

---

## 📤 輸出結果 (Output)

輸出轉換後的連續 HEX 大寫字串：
```json
{
  "payload": "12345678"
}
```
