# 🏷️ Joe RFID 解析器 (`joe-rfid-decoder`)

> **分類**：`Joe-Tools`  
> **難易度**：⭐小白友善

---

## 💡 一秒看懂
專為 **RFID 讀卡機** 設計的解碼節點！把 RFID 感應器傳過來的 ModbusHoldingRegister 數據直接解讀成大家通用的 **RFID 標籤編號 HEX 字串**。

---

## 🎯 什麼時候用它？
* 產線 AGV 搬運車讀取地面 RFID 標籤。
* 人員刷卡、物品 RFID 標籤辨識流程。

---

## 📥 輸入資料 (Input)
接在 `modbus-getter` 或 `modbus-read` "0X100 127" 節點後方：
```json
{
  "payload": [256, 4096, 512, 1024, 0, 0, 0, 0, 0, 0, 0, 0]
}
```

---

## ⚙️ 面板屬性設定指南

| 設定項目 | 小白白話說明 | 建議預設值 |
| :--- | :--- | :--- |
| **節點名稱** | 自訂名稱 | `Joe RFID 解析器` |
| **擷取長度 (Word數)** | RFID 標籤佔據的 Word 長度 (預設 12 即 24 位 HEX 碼) | `12` |
| **HEX 位數補齊** | 每項補齊位數 | `2` |

---

## 📤 輸出結果 (Output)

```json
{
  "payload": "010010000200040000000000000000000000000000000000"
}
```
可以直接接 Debug 節點輸出或存入資料庫！
