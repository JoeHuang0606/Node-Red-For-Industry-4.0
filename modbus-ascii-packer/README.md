# 📦 Modbus ASCII 打包器 (`modbus-ascii-packer`)

> **分類**：`Joe-Tools`  
> **難易度**：⭐小白友善

---

## 💡 一秒看懂
這個節點是幫你把**文字（字串）**轉成 PLC / Modbus 能看得懂的**數字陣列 (Uint16Array)**。  
比如你想把工單號碼 `"ABC12345"` 寫進 PLC 暫存器，直接傳字串 PLC 不認識，拉這個節點幫你轉好再寫入！

---

## 🎯 什麼時候用它？
* 當你需要將條碼、QR碼、產品批號或工單號碼寫入 Modbus PLC 暫存器時。
* 需要自動觸發 PLC 開始寫入命令（例如觸發 0x0400 寫入動作）。

---

## 📥 輸入資料 (Input)
輸入你想要寫入的文字字串：
```json
{
  "payload": "ABC12345"
}
```

---

## ⚙️ 面板屬性設定指南

| 設定項目 | 小白白話說明 | 建議預設值 |
| :--- | :--- | :--- |
| **節點名稱** | 給這個節點取個你自己看的懂的名字 | `Modbus ASCII 打包器` |
| **總 Word 數** | PLC 預留給字串的總空間大小 (1 Word = 2字元) | `32` |
| **有效 Word 數** | 最多只處理前面幾個 Word (超過會切掉) | `8` (代表最多處理 16 個字元) |
| **觸發延遲 (秒)** | 資料轉換完成後，隔幾秒發送啟動訊號給 PLC | `1.0` |
| **觸發數值** | 發送給 PLC 啟動開關的數值 | `1` |

---

## 📤 輸出結果 (Output)

本節點有 **2 個腳位輸出**：

* **Output 1 (上方腳位 - Modbus Data)**：
  轉好的 Uint16Array 數值陣列（直接接給 Modbus-Write 寫入資料暫存器）。
  ```json
  [16962, 17219, 13109, 13621, 0, 0, 0, 0]
  ```

* **Output 2 (下方腳位 - CMD Trigger Signal)**：
  延遲特定時間後輸出的觸發數值（直接接給 Modbus-Write 觸發寫入開關暫存器）。
  ```json
  1
  ```

---

## 💡 小白避坑指南
1. 一個 Modbus Word 可以藏 2 個 ASCII 英文字母/數字。
2. 若傳入非字串，節點會貼心自動幫你 `toString()` 再處理，不用擔心當機。
