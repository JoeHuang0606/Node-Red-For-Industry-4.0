# 📡 Joe 超聲波解析器 (`joe-ultrasonic-parser`)

> **分類**：`Joe-Tools`  
> **難易度**：⭐小白友善

---

## 💡 一秒看懂
自動將**超聲波距離感測器**讀回來的原始數據轉換成乾淨的**小數距離值 (距離/高度/液位)**。支援 Modbus 與 MQTT 兩種資料來源！

---

## 🎯 什麼時候用它？
* 測量液位高度、物體距離防撞監測。

---

## 📥 輸入資料 (Input)

### 情況 A：Modbus "256 1"模式
```json
{
  "payload": 56704
}
```

### 情況 B：MQTT 模式 (IO 模組傳入 2-byte)
```json
{
  "payload": {
    "in_data_cha": [0, 221]
  }
}
```

---

## ⚙️ 面板屬性設定指南

| 設定項目 | 小白白話說明 | 可選項目 |
| :--- | :--- | :--- |
| **節點名稱** | 自訂名稱 | `Joe 超聲波解析器` |
| **解析模式** | 選擇資料來源格式 | 1. **自動判斷 (Auto)**：自動辨識資料類型<br>2. **Modbus 暫存器模式 (除以 1024)**<br>3. **MQTT 2-Byte 模式 (除以 4)** |

---

## 📤 輸出結果 (Output)

```json
{
  "payload": {
    "raw": 56704,
    "distance": 55.4
  }
}
```
`distance` 即為精確至小數點後一位的距離值。
