# 📊 變數視覺化管理員 (`variable-change`)

> **分類**：`Joe-Tools`  
> **難易度**：⭐小白友善

---

## 💡 一秒看懂
不用寫 `flow.set('a', 1)` 或 `global.set('b', 2)` 程式碼！  
拉這個節點，可以直接在畫面上用**拖曳排序**與**選單設定**來一次修改多個 Flow 或 Global 全域變數。

---

## 🎯 什麼時候用它？
* 需要初始化多個變數或配方參數。
* 需要在流程運作中批次修改跨頁面使用的 Global 變數。

---

## ⚙️ 面板屬性設定指南

* **作用域選擇**：可選 `flow` (僅當前頁面有效) 或 `global` (全專案有效)。
* **運作模式**：
  * **即時模式 (Realtime)**：部署或收到輸入時立即寫入變數。
  * **初始化模式 (Initialization)**：僅在系統啟動時初始化變數。
* **拖曳排序**：滑鼠拖動左側圖示可上下調整變數寫入順序。

---

## 📤 輸出結果 (Output)

```json
{
  "payload": "Variables updated successfully"
}
```
變數將自動寫入系統 Context 中！
