# 🏷️ RFID 智慧讀寫模組 (`rfid-helper`)

> **分類**：`Joe-Tools`  
> **難易度**：⭐小白友善

---

## 💡 一秒看懂
工業級 RFID 智慧控制助手。具備**自動分批寫入**與**卡片離開通知**功能。防止一次寫入過長資料導致卡片掉線或寫入失敗。

---

## 🎯 什麼時候用它？
* 需要對 RFID 卡片的 USER 記憶區寫入長字串。
* 需要防碰撞、防掉線，以及在卡片移開時發送離場通知。

---

## ⚙️ 面板屬性設定指南

| 設定項目 | 小白白話說明 | 建議預設值 |
| :--- | :--- | :--- |
| **讀取限制 (Word)** | 單次讀取最大限制，防止通訊超時 | `16` |
| **自動分批寫入** | 自動將長字串拆分寫入卡片 | 勾選 `true` |
| **離開超時 (秒)** | 卡片離開多久後觸發離開警報通知 | `2.0` |

---

## 📤 輸出結果 (Output)

```json
{
  "payload": {
    "status": "TAG_REMOVED",
    "last_tag_id": "E200001621090123"
  }
}
```
廣泛應用於工業卡片流轉監控。
