# ⚡ Joe Omron 電力計解析器 (joe-power-parser)

## 💡 一秒看懂
把 Omron 電力計透過 Modbus 讀回來的「電壓 + 電流」原始數字，自動換算成實際的 **伏特 (V)**、**安培 (A)** 與 **瓦特 (W)**！

---

## 🎯 使用場景
- 監控 Omron 電力計的電壓與電流
- 搭配 Dashboard 即時顯示功率消耗

---

## 📥 輸入資料 (Input)
讀取 Modbus 3 個暫存器 "0 3" 的陣列輸入：
```json
{
  "payload": [0, 2205, 350]
}
```
- `payload[0]`：狀態暫存器（不使用）
- `payload[1]`：電壓原始值（2205 ➔ 22.05V）
- `payload[2]`：電流原始值（350 ➔ 3.50A）

> 💡 手冊定義原始值 0~9990 對應實際值 0.00~99.90

## 📤 輸出結果 (Output)

```json
{
  "payload": {
    "Voltage_V": 22.05,
    "Current_A": 3.50,
    "Power_W": 77.2
  }
}
```
可以直接接 Dashboard 圖表或存入資料庫！
